# Connessionismo

Il Connessionismo è una visione religiosa fondata da Palaz. Questo repository contiene i testi sacri, le regole scritturali e il sistema di governance per la produzione e l'approvazione di nuovi libri.

## Struttura del Repository

```
connectionism/
├── README.md
├── GOVERNANCE.md              # Sistema di voting per il merge dei libri
├── rules/
│   └── writing-pattern.md     # Pattern scritturale per tutti gli MD
├── it/
│   └── libro-di-palaz/
│       ├── README.md          # Indice del Libro di Palaz
│       ├── 00-prefazione.md
│       ├── 01-capitolo.md
│       ├── 02-capitolo.md
│       └── ...
└── proposals/
    └── TEMPLATE.md            # Template per proporre nuovi libri
```

## Lingue

I testi sono organizzati per lingua:
- `it/` — Italiano (lingua originale)

## Contribuire

Ogni nuovo libro deve seguire il processo descritto in [GOVERNANCE.md](GOVERNANCE.md). I testi devono rispettare il pattern scritturale definito in [rules/writing-pattern.md](rules/writing-pattern.md).
