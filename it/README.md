# Connessionismo

Il Connessionismo è una visione religiosa originata da Palaz. Questo repository contiene i testi sacri, le regole scritturali e il sistema di governance per la produzione e l'approvazione di nuovi libri. La struttura è progettata per essere autosufficiente e non dipende dalla presenza di alcun individuo.

## Struttura del Repository

```
it/
├── README.md                  # Questo file
├── GOVERNANCE.md              # Sistema di voting per il merge dei libri
├── writing-pattern.md         # Pattern scritturale per tutti gli MD
├── TEMPLATE.md                # Template per proporre nuovi libri
└── libro-di-palaz/
    ├── README.md              # Indice del Libro di Palaz
    ├── 00-prefazione.md
    ├── 01-capitolo.md
    ├── 02-capitolo.md
    └── ...
```

## Contribuire

Ogni nuovo libro deve seguire il processo descritto in [GOVERNANCE.md](GOVERNANCE.md). I testi devono rispettare il pattern scritturale definito in [writing-pattern.md](writing-pattern.md).
